## Anderson Silva

**Senior Front-End Engineer · 3D Web Applications & Product Configurators**

I build the 3D applications that turn a browser into a manufacturing tool.

For eight years I was a CG Technical Director leading VFX teams for broadcast, the role that sits
between the artists and the engineers. I do the same thing today on the web: when a boolean
operation fails, I can tell whether the bug is in the algorithm or in the mesh topology, and I can
fix it on either side.

### What I work on

- Real-time boolean CSG in the browser (`three-bvh-csg`, `manifold-3d`, BVH acceleration)
- Mesh repair, voxel remeshing and watertight geometry for 3D printing
- Custom 3MF / OBJ / STL exporters with vertex-colour support
- Monorepo architecture (Turborepo, pnpm), design systems and render performance
